# 反 PPT 门禁（Anti-PPT gates）

> 来源：用户实战总结（2026-10）。适用于一切"用代码/生成方式做的短片"。
> **PPT 感的根因不是运镜差，是"直译"**：把输入原样搬运——剧本写"一个人在雨里"，画面就"一个人+雨+淡入"。它不丑，但它没有发生任何事。所有有效手段都指向同一个目标：**强迫画面里存在"变化"，而不是"内容"**。

## 0. 两条硬规则（先于一切）

1. **规划与执行物理分开。** 不要在理解剧情的同时写代码——那必然滑向最低成本路径（把文字摆上去、淡入淡出）。先产出一份**逐镜决策清单**（见 §2 模板），清单过审后才允许写实现。
2. **只描述"什么在变"，禁止描述"有什么"。** "角色站在房间里"是 PPT 语言；"从静止到转身，经过三个可辨识的中间姿态"才是动画语言。动作必须有可辨识的起止和中间姿态。

## 1. 可勾选门禁（每镜都要过；不能勾 = 未完成）

| ID | 门禁 | 判定方法（可检查） | 反例 |
|---|---|---|---|
| **G1 变化三姿态** | 每镜写清"A 状态 → 中间 3 个可辨识姿态 → B 状态" | 清单条目里有起止 + 至少 3 个具名中间姿态 | 只写"卡片出现" |
| **G2 动词/程度数字化** | 禁用"轻微 / 微微 / 淡淡 / 缓慢地 / 大约"；任何程度必须给数字（px、秒、帧、角度、dB） | 在清单里 grep 禁用词 = 0 | "略微上浮" |
| **G3 环境持续变化** | 每镜至少有 1 个环境元素**持续**变化：尘、光束、阴影漂移、材质呼吸、粒子 | 写明元素 + 公式/频率；同镜取 4 帧，该元素位置/亮度必须不同 | 背景完全冻结 |
| **G4 相机主动选择** | 每镜记录相机（推/拉/横移/升降/固定）+ 理由；"固定机位"必须说明为什么这一拍要固定 | 清单中有相机字段 + 理由字段 | 默认静止 = 幻灯片 |
| **G5 删镜测试** | 删掉这一镜剧情仍成立 → 删掉它；填充物天生像 PPT | 每镜写"删掉会缺哪一拍"，缺得不够狠就砍 | "过渡用的空镜" |
| **G6 情绪 → 参数** | 每个情绪点翻译成可渲染参数：速度、幅度、粒子密度、阴影硬度、色温、景别 | 清单中"情绪→参数"一栏写的是数字/参数，不是形容词 | "这里要紧张" |
| **G7 技法反向长剧情** | 全片至少 1 处情节是"先想到 AI 能稳定做的技法（粒子离散/材质变形/逐帧顿挫/切镜），再反推出来的" | 清单里标出哪一镜是反向长出来的 | 剧情定了再贴效果 |
| **G8 技法稳定性优先** | 优先用镜头切换、局部特写、材质变化、粒子承载替代高风险连续动作；**做糊的复杂动作比不做更 PPT** | 清单里标注风险：低/中/高；高风险必须有降级方案 | 硬写复杂连续肢体动作 |
| **G9 元规则：可勾选** | 抽象要求必须翻译成可勾选门禁。"要有寓意""要精彩"不能进验收 | 验收清单每一条都能打勾 | "结尾加一句意味深长的话"冒充深度 |

## 2. 每镜决策条目模板（DECISION-LIST）

```markdown
### S0x  <起–止秒> · 一句话
- 变化：<A 状态> →(0.0s) <P1> →(0.6s) <P2> →(1.3s) <P3> → <B 状态>
- 环境持续变化：<元素> <公式/频率>
- 相机：<推/拉/横移/升降/固定>；理由：<为什么这一拍这样拍>
- 删镜测试：删掉会缺 <哪一拍>；<不删的理由>
- 情绪 → 参数：<情绪> = <速度/幅度/粒子/阴影/色温>
- 技法稳定性：<用什么替代高风险动作>；风险：低/中/高 + 降级方案
- 声音对位：<事件> @ <t 秒>
```

## 3. 渲染前/后的检查手段

- **0.2s 动作条**（必做）：`node render.mjs --sheet=t,t+.2,t+.4,…,t+1.0 --cols=4 --w=480 --out=out/check/strip.jpg`。少于 3 个可辨识状态 = 回炉。
- **两帧差测试**：同一镜内任意间隔 ≥0.3s 的两帧必须不同，且差异不能只是整体位移（要看内容区变化）。
- **环境变化抽检**：同镜 4 帧里，尘/光/粒子位置必须不同。
- **删镜复读**：把这一镜从时间轴上删掉再读一遍全片，节奏和剧情是否还成立。

## 4. 反模式清单

- "内容 + 淡入淡出" = PPT
- 整帧 Ken Burns 式推拉 = 会动的 PPT
- 元素整体滑入 = PPT
- 默认固定机位 = 幻灯片翻页
- 停顿里没有次级层运动 = 死帧
- 结尾加一句意味深长的话冒充深度 = 伪深刻（母题要让观众自己发现；结尾是动作结束，不是解释开始）

## 5. 一句话

**能被检查的规则才会被执行；不能被检查的形容词只会被敷衍。**
